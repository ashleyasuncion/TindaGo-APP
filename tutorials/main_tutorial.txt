SARI-SARI SMART (ANDROID) — MAIN TUTORIAL (14 STEPS)
====================================================
Config: NavGraph.kt -> val tutorialSteps
Type: multi-page full-flow tutorial
Pages: morning -> day -> closing -> inventory -> debts -> settings
Launch: auto on fresh app launch (once per app session); also from Settings -> Tutorial selector
        / Help -> "Replay Tutorial" (both route through startPageTutorial("main") -> startTutorial(replay = true)
        and navigate to Morning, behaving identically to the auto-launch)

SHARED STEP FIELDS
- Highlight appearance: pure outline — transparent center (element stays visible), white 2dp inner ring +
  green 4dp outer ring (offset 2dp outward), rounded corners ~12-14dp, -4dp offset around the target
- Navigation: Previous appears from step 2 onward; Next advances; on step 14 the button reads
  "Get Started" and FINISHES, returning the user to the Morning page (web v2.40 parity);
  Skip (left side) + backdrop tap dismiss only on replay
- Box position rule: no highlight -> bottom center; target center in top 45% of screen -> card at bottom;
  otherwise card at top (below the header pill)
- Page transitions: Next navigates when the next step's page differs (popUpTo(MORNING) + launchSingleTop);
  Previous walks back through the same route mapping; DAY/CLOSING entry guards are skipped while active
